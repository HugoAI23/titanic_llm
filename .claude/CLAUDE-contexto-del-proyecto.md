# Proyecto escolar para aprendizaje supervisado

## Resumen del proyecto
- Es un proyecto escolar de mi carrera de ingeniería en inteligencia artificial
- Se tiene un dataset con información del Titanic en la carpeta data
- Con esta información se va a construir un LLM para predecir la supervivencia de los viajeros en el barco
- Se hará una limpieza de los datos
- Se hará un EDA para obtener insights del dataset
- Se hará Feature Engineering para poder construir el modelo
- El algoritmo que se pretende hacer en Random Forest y Regresión Logística
- Se hará el entrenamiento de los modelos y luego las predicciones
- Soy primerizo haciendo esto
